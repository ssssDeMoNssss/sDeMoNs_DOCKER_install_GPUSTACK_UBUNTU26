# README.md для скрипта `sDeMoNs_DOCKER_install_GPUSTACK_UBUNTU26.sh`

```markdown
# sDeMoNs_DOCKER_install_GPUSTACK_UBUNTU26.sh

Интерактивный bash-скрипт для полной установки **Docker Engine**, **NVIDIA Container Toolkit** и **GPUStack** (Server или Worker) на **Ubuntu 26.04 LTS** с нуля.

Скрипт автоматически:
- удаляет конфликтующие пакеты Docker;
- устанавливает официальный Docker Engine;
- настраивает NVIDIA runtime для доступа к GPU из контейнеров;
- задаёт вопросы о роли узла (сервер / воркер), IP-адресах, порте и токене;
- запускает соответствующий контейнер GPUStack.

## 📋 Требования

- **ОС**: Ubuntu 26.04 LTS (для других версий скрипт выдаст предупреждение и запросит подтверждение).
- **Права**: запуск с `sudo`.
- **Драйвер NVIDIA**: на хосте должен быть установлен проприетарный драйвер NVIDIA (рекомендуется версия 550 или новее). Без него проверка `nvidia-smi` внутри контейнера не пройдёт, и скрипт предложит продолжить на свой страх и риск.
- **Аппаратная виртуализация**: для работы Docker Desktop не требуется (скрипт использует Docker Engine), но для GPUStack желательно наличие KVM (не обязательно).
- **Интернет**: доступ к репозиториям Ubuntu, Docker и NVIDIA.

## 🚀 Быстрый старт

1. Сохраните скрипт в файл `sDeMoNs_DOCKER_install_GPUSTACK_UBUNTU26.sh`.
2. Сделайте его исполняемым:
   ```bash
   chmod +x sDeMoNs_DOCKER_install_GPUSTACK_UBUNTU26.sh
   ```
3. Запустите с правами root:
   ```bash
   sudo ./sDeMoNs_DOCKER_install_GPUSTACK_UBUNTU26.sh
   ```
4. Отвечайте на интерактивные вопросы.

## 🧠 Интерактивная настройка

При запуске скрипт попросит выбрать роль узла:

```
Выберите роль этого узла:
  1) Server (главный узел, хранит данные и управляет кластером)
  2) Worker (рабочий узел, предоставляет GPU-ресурсы серверу)
```

### Для серверного узла (Server)

- Введите IP-адрес этого сервера (например, `192.168.1.235`).
- Укажите порт (по умолчанию `9090`).

После установки вы получите:
- Веб-интерфейс: `http://<IP_сервера>:<порт>`
- Логин: `admin`
- Пароль администратора можно узнать командой:
  ```bash
  docker exec -it gpustack cat /var/lib/gpustack/initial_admin_password
  ```
- Токен для подключения воркеров:
  ```bash
  docker exec -it gpustack cat /var/lib/gpustack/token
  ```

### Для рабочего узла (Worker)

- Введите IP-адрес этого воркера (например, `192.168.1.236`).
- Введите IP-адрес сервера GPUStack.
- Укажите порт сервера (по умолчанию `9090`).
- Введите токен, полученный на сервере (см. выше).

После установки воркер автоматически подключится к серверу.

## ⚙️ Что делает скрипт (пошагово)

1. **Проверка прав и ОС** — убеждается, что скрипт запущен с `sudo` и система является Ubuntu 26.04.
2. **Проверка виртуализации** — предупреждает, если KVM недоступен (не критично для GPUStack).
3. **Интерактивный опрос** — собирает параметры для сервера или воркера.
4. **Удаление конфликтов** — удаляет `docker.io`, `docker-desktop`, `podman-docker` и другие пакеты, мешающие установке Docker Engine.
5. **Установка базовых зависимостей** — `curl`, `gnupg`, `lsb-release`, `jq` и др.
6. **Подключение репозитория Docker** — добавляет официальный GPG-ключ и репозиторий для Ubuntu 26.04.
7. **Установка Docker Engine** — `docker-ce`, `docker-ce-cli`, `containerd.io`, `docker-buildx-plugin`, `docker-compose-plugin`.
8. **Добавление пользователя в группу `docker`** — чтобы можно было работать без `sudo`.
9. **Установка NVIDIA Container Toolkit** — добавляет репозиторий NVIDIA и устанавливает toolkit.
10. **Настройка Docker для NVIDIA runtime** — `nvidia-ctk runtime configure --runtime=docker` и перезапуск Docker.
11. **Проверка GPU** — запускает тестовый контейнер с `nvidia-smi`. При неудаче предлагает продолжить.
12. **Запуск GPUStack**:
    - Для **сервера**: `docker run` с флагами `--port` и `--advertise-address`.
    - Для **воркера**: `docker run` с `--runtime nvidia`, `GPUSTACK_TOKEN`, `--server-url` и `--worker-ip`.
13. **Финальные инструкции** — выводит команды для управления контейнером и получения пароля/токена (для сервера).

## 🔍 Проверка работы

- Логи контейнера:
  ```bash

- Проверка GPU в Docker (независимо от GPUStack):
  ```bash

  Если команда выводит таблицу с информацией о GPU — всё настроено верно.

## ⚠️ Возможные проблемы и их решение

### Ошибка `unknown or invalid runtime name: nvidia`

Возникает, если не установлен или не настроен NVIDIA Container Toolkit. Скрипт выполняет эту настройку автоматически. Если ошибка появилась, проверьте, что пакет `nvidia-container-toolkit` установлен, и выполните:
```bash
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

### Ошибка `failed to connect to the docker API`

Убедитесь, что служба Docker запущена:
```bash
sudo systemctl status docker
sudo systemctl start docker
```

### Тестовый контейнер с GPU не запускается

Скорее всего, на хосте не установлен драйвер NVIDIA. Установите его:
```bash
sudo apt install nvidia-driver-550
sudo reboot
```
После перезагрузки проверьте `nvidia-smi` на хосте.

### Контейнер GPUStack не запускается

Проверьте логи:
```bash
docker logs gpustack
```
Частая причина — неверный токен (для воркера) или недоступность сервера.
